# Журнал изменений

## 0.5.5 — 2026-09-14

Безопасные Matrix-команды, зашифрованные снимки камер и автоматический Voice Assist.

- Добавлены fail-closed действия `matrix_extended.register_command` и `matrix_extended.unregister_command` для точных разрешённых Matrix-команд с сохранением определений.
- Действие Home Assistant, target, data и сущность камеры хранятся на стороне интеграции: входящий Matrix-текст может только выбрать зарегистрированную команду и не может подменить выполняемое действие.
- Добавлен обработчик команды `camera_snapshot`, который делает снимок настроенной `camera.*` сущности и возвращает изображение в Matrix с E2EE.
- Добавлена необязательная автоматическая обработка нативных голосовых Matrix: расшифровка/скачивание → Home Assistant STT → Conversation/Assist → ответ обратно в Matrix.
- Добавлены отдельные ограничения Voice Assist по пользователям и комнатам, которые могут только сужать обычные входящие allowlist, а также режимы ответа `text`, `voice` и `both`.
- В графический Options Flow Home Assistant добавлен отдельный раздел **Voice Assist**.
- Добавлены диагностики готовности E2EE, размера outbox, статуса последней доставки и последней команды с английскими и русскими переводами.
- `services.yaml` проверен реальным parser Home Assistant 2026.9.2, включая новые действия команд.
- Зашифрованные safe commands, снимки камер и автоматический Voice Assist проверены на полном стенде Home Assistant 2026.9.2 + Synapse 1.160.0 + Element 1.12.26.
- Повторно проверены encrypted send/reload, notify entities, отображение в Element, `send_media`, восстановление после падения Synapse, persistent outbox, перезапуск Home Assistant и отсутствие зависших background tasks.

### Совместимость

- Breaking changes для существующих автоматизаций нет.
- Автоматический Voice Assist остаётся opt-in и по умолчанию выключен.
- Безопасные Matrix-команды выполняют только заранее зарегистрированные определения и fail-closed отклоняют незарегистрированный или запрещённый ввод.

## 0.5.4 — 2026-09-14

Графический интерфейс Home Assistant в приоритете и очистка публичного репозитория.

- Разделены настройки интеграции на **Основное**, **Входящие и безопасность**, **Входящие медиа** и **Маршруты уведомлений**.
- Ручное редактирование маршрутов в JSON заменено на графические операции добавления, изменения и удаления.
- Комната по умолчанию и проверка TLS теперь изменяются из интерфейса интеграции, а runtime после перезагрузки использует сохранённые значения.
- Для config entry, TTS/STT-сущностей, языка, сущностей геопозиции, Media Browser, targets и структурированных расширенных полей используются штатные selectors Home Assistant там, где это возможно.
- YAML-совместимость сохранена для всех действий и расширенных provider-specific параметров.
- Локализованы диагностические состояния, включая шифрование и тип последнего входящего события; при отсутствии ошибки показывается `Ошибок нет`, а не неизвестное состояние.
- Обновлена английская и русская документация, из пользовательской части репозитория удалены внутренние планы, спецификации и служебные материалы mutation-testing.
- Проверки структуры, привязанные к конкретным номерам релизов, заменены актуальными поведенческими/контрактными тестами; из source validation убрана необходимость вручную менять номер версии.

## 0.5.3 — 2026-09-14

Исправления runtime, проверенные на полном стенде Home Assistant + Synapse + Element.

- Исправлена регистрация обработчика `matrix_extended.send_media`, чтобы Home Assistant вызывал графическое действие отправки медиа с правильной сигнатурой.
- Исправлена совместимость Media Source browsing/delivery для графического медиапикера.
- Улучшен fallback языка TTS, когда провайдер публикует совместимый язык с другой детализацией locale.
- Метаданные доставки нативных голосовых сообщений Matrix приведены к допустимому типу media.
- Диагностика **Последнее входящее событие** расширена типом события и специфичными для события атрибутами.
- В real-stack CI добавлены регрессии на `send_media` и расширенную диагностику входящих событий.

Локализованные действия и графический выбор медиа.

- Добавлено `matrix_extended.send_media` со штатным Home Assistant Media Browser.
- Добавлены английские и русские переводы действий/полей и переводимые варианты selectors.
- На реальном Home Assistant проверены notify-сущность по умолчанию и отдельные notify-сущности комнат.
- Сохранена существующая расширенная модель `media` для камер, URL, локальных путей, нескольких вложений и Matrix-специфичных метаданных.

## 0.5.1 — 2026-09-14

Runtime/install hotfix для Home Assistant 2026.9.

- Matrix E2EE теперь устанавливается через `matrix-nio[e2e]==0.26.0` непосредственно из manifest интеграции, а не только из тестового окружения.
- Исправлены числовые метаданные action selectors, чтобы `services.yaml` принимался реальной схемой метаданных Home Assistant.
- Добавлен чистый Python 3.14 gate: установка только зависимостей из manifest и проверка E2EE import/configuration.
- Метаданные служб проверяются реальным parser Home Assistant 2026.9.2 до сборки пакета.

## 0.5.0 — 2026-09-13

Релиз автоматизаций, rich messages, голоса и геопозиции для Home Assistant 2026.9+.

### Сообщения и API автоматизаций

- Добавлен структурированный ответ `matrix_extended.send` со стабильным `delivery_id`, статусом `sent` / `queued` и записями Matrix events.
- Добавлены lifecycle events `matrix_extended_delivery` для `sent`, `queued`, `failed` и `dropped`.
- Добавлены типы Matrix-сообщений `text`, `notice` и `emote`.
- Добавлен безопасный рендеринг Markdown в Matrix HTML с сохранением исходного Markdown body как fallback.
- Добавлены нативные Matrix mentions через `mention_users` и room mentions.
- Расширены метаданные входящих событий, добавлены события редактирования и redaction.

### Действия по реакциям

- Reaction actions сохраняются между перезапусками Home Assistant.
- Добавлены ограничения `expires_in`, `max_uses` и `allowed_users`.
- Выполнение остаётся fail-closed: Matrix-текст, YAML и Jinja не исполняются как произвольные Home Assistant services.

### Голос

- Добавлены нативные Matrix voice-message metadata для исходящего аудио при сохранении совместимости со стандартным `m.audio`.
- Добавлено `matrix_extended.send_voice`: синтез текста через Home Assistant TTS и отправка как Matrix voice message.
- Добавлено `matrix_extended.transcribe_voice`: распознавание скачанного Matrix voice через Home Assistant `stt.*` entity.
- Добавлена нормализация OGG/Opus → WAV/PCM через Home Assistant FFmpeg, когда это требуется локальным STT-провайдерам вроде Wyoming/Whisper.
- Добавлена явная opt-in передача транскрипта в Home Assistant Conversation/Assist через `assist: true`; голосовые сообщения никогда не запускают Assist-команды по умолчанию.
- Пути голосовой транскрипции ограничены собственной директорией входящих медиа Matrix Extended для выбранного аккаунта.

### Геопозиция

- Добавлено `matrix_extended.send_location` для стабильной отправки Matrix `m.location` по явным координатам или Home Assistant entities с latitude/longitude.
- Добавлены входящие события `matrix_extended_location`.
- Поддержаны зашифрованная отправка геопозиции и lifecycle records доставки.

### Входящие медиа и retention

- Добавлена настраиваемая очистка входящих медиа по возрасту и максимальному объёму хранилища.
- Добавлено `matrix_extended.purge_media` с response data о количестве удалённых файлов и освобождённых байтах.
- Очистка ограничена только директориями входящих медиа, которыми владеет интеграция.

### Надёжность и проверка

- Real-stack CI расширен до Home Assistant 2026.9.2 + Synapse 1.160.0 + Element Web 1.12.26.
- Проверено, что реальный получатель Element расшифровывает E2EE-сообщения Home Assistant.
- Проверены зашифрованная геопозиция и нативное отображение voice messages в Element, включая реальные client screenshots.
- Проверены восстановление persistent outbox после недоступности Synapse, восстановление входящих событий, перезапуск Home Assistant и сохранение одноразовых reaction actions.
- Сохранён gate проверенного install ZIP с побайтовым сравнением component tree и SHA-256 checksum.

### Совместимость

- Существующие `matrix_extended.send`, notify entities, routing profiles, replies, reactions, edits, redactions и media automations остаются совместимыми.
- Тип исходящего сообщения по умолчанию остаётся `text`, формат — plain text.
- Сохраняется `matrix-nio==0.26.0`: он не поддерживает Matrix cross-signing и отправляет `m.reaction` без шифрования; реакции не следует использовать для секретных данных.

## 0.4.2 — 2026-09-12

Релиз надёжности, проверенный на реальных Home Assistant 2026.9.2 и Synapse 1.160.0.

- Исправлена установка E2EE в окружениях Home Assistant, где встроенная Matrix-интеграция уже удовлетворяет базовую зависимость `matrix-nio==0.26.0`; необходимые E2EE runtime dependencies объявлены явно.
- Исправлена диагностика соединения при недоступности homeserver: транспортные retries matrix-nio ограничены, поэтому Matrix Extended может зафиксировать disconnect и запустить собственный reconnect loop.
- Проверено автоматическое восстановление входящих событий и зашифрованной исходящей отправки после перезапуска Synapse без reload Home Assistant.
- Файловый доступ crypto-store `restore_login()` вынесен из event loop Home Assistant.
- Добавлен real-stack CI для config flow, encrypted send, reload, Synapse outage/recovery, inbound recovery, перезапуска Home Assistant и проверки runtime-логов.
- Добавлен gate release-пакета: install ZIP создаётся только после обязательных тестов, его содержимое побайтово сравнивается с component tree и публикуется с SHA-256 checksum.
