# Настройки Matrix Extended

Matrix Extended рассчитан прежде всего на настройку из интерфейса Home Assistant. Для настройки самой интеграции YAML не нужен.

Откройте **Настройки → Устройства и службы → Matrix Extended → Настроить**. Options Flow разделён на четыре раздела.

## Основные

- **Комната по умолчанию** — Matrix Room ID (`!...`) или alias (`#...`). Используется, если действие не задаёт `Комнаты` или `Маршрут`.
- **Проверять TLS-сертификат** — оставляйте включённым для обычного HTTPS homeserver. Выключать стоит только для заведомо доверенного локального/тестового сервера.
- **Требовать E2EE** — при включении Matrix Extended отказывается отправлять сообщения в незашифрованные целевые комнаты.

Изменение комнаты по умолчанию или TLS перезагружает config entry, поэтому runtime начинает работать уже с новым значением.

## Входящие и безопасность

- **Принимать входящие события** — включает обработку входящих Matrix events.
- **Разрешённые пользователи** — Matrix ID отправителей, которым разрешено попадать в Home Assistant.
- **Разрешённые комнаты** — комнаты Matrix, из которых разрешена обработка событий.

Политика fail-closed: если входящие события включены, оба allowlist должны быть непустыми, а входящее событие должно одновременно совпасть и по отправителю, и по комнате. Собственные transaction echoes игнорируются.

Для автоматизаций с чувствительными действиями лучше использовать отдельный Matrix-аккаунт и отдельные комнаты.

## Входящие медиа

- **Скачивать и расшифровывать входящие медиа** — сохранять вложения Matrix локально для автоматизаций.
- **Хранить, дней** — очистка по возрасту. `0` отключает удаление по возрасту.
- **Лимит хранилища, МиБ** — максимальный размер каталога входящих медиа интеграции.

Файлы сохраняются в:

```text
/config/matrix_extended/incoming/<config_entry_id>/
```

Для немедленной ручной очистки есть действие `matrix_extended.purge_media`.

## Маршруты уведомлений

Маршрут — это удобное имя для одной или нескольких Matrix-комнат. Маршруты полностью управляются графически через **Добавить маршрут**, **Изменить маршрут** и **Удалить маршрут**.

Пример:

```text
security → !garage:example.org, !gate:example.org
```

После этого автоматизация может использовать `route: security` вместо двух жёстко прописанных Room ID. `route` и явный `target`/Комнаты одновременно не используются.

## Select комнаты по умолчанию

Matrix Extended также создаёт select-сущность **Комната по умолчанию** со списком joined rooms. Изменение select сохраняет выбранную комнату и обновляет default room интеграции.

## Диагностика

Устройство интеграции показывает:

- состояние соединения;
- Matrix user/device ID;
- комнату по умолчанию и состояние её шифрования;
- последнюю успешную отправку;
- последнее входящее событие с его атрибутами;
- последнюю ошибку (`Ошибок нет`, если всё нормально).

## Постоянные данные

E2EE crypto-state и внутренние registry хранятся в Home Assistant storage. Не редактируйте эти файлы вручную во время работы Home Assistant.

```text
/config/.storage/matrix_extended/<config_entry_id>/
```
